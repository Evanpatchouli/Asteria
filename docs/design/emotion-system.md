# Emotion System

版本：v0.1

## 1. 目标

将简单状态升级为具有表现力的情绪系统。

## 2. State 与 Emotion 分离

State：

表示当前任务。

例如：

coding

Emotion：

表示角色状态。

例如：

happy focused tired

最终行为：

State + Emotion = Behavior

## 3. 情绪类型

基础：

-   normal
-   happy
-   excited
-   tired
-   confused
-   sleepy

## 4. 情绪来源

来源：

-   Agent 事件
-   使用时间
-   用户交互
-   任务结果

## 5. 第一阶段

MVP 不实现复杂 AI 情绪模型。

采用：

规则驱动。
