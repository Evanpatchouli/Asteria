# Interaction Design

版本：v0.1

## 1. 目标

定义 AI Agent Desktop Companion 与用户之间的交互体验。

核心目标：

让用户感受到这是一个陪伴角色，而不是状态指示器。

## 2. 交互原则

-   状态可感知
-   行为自然
-   避免频繁打扰
-   保持角色一致性

## 3. Agent 状态映射

### Coding

事件：

agent.coding

行为：

-   坐下工作
-   敲键盘
-   偶尔观察屏幕

### Thinking

事件：

agent.thinking

行为：

-   思考动作
-   注视屏幕
-   等待反馈

### Success

事件：

agent.success

行为：

-   庆祝
-   开心表情

### Error

事件：

agent.error

行为：

-   疑惑
-   检查问题

## 4. 用户交互

支持：

-   点击宠物
-   拖动位置
-   查看状态
-   打开设置

## 5. 桌面窗口交互

MVP 窗口行为：

-   首次启动显示在主显示器工作区右下角，距右侧和底部各 `24px`
-   拖动完成后保存窗口位置
-   重启时精确恢复仍横纵各有至少 `64px` 可见的部分离屏位置
-   可见范围不足时仅移动到横纵各保留至少 `64px`，完全离屏时回退主屏右下角
-   显示器移除或工作区变化时按相同规则恢复窗口
-   整窗口鼠标穿透由 Main Process 管理
-   系统托盘始终提供关闭穿透、显示窗口和退出应用的恢复入口

窗口显示使用非激活方式，避免桌宠抢占用户当前应用的焦点。
