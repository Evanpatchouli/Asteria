# Contribution Guide

版本：v0.1

## 1. 开发原则

遵循：

-   模块化
-   类型安全
-   事件驱动
-   最小耦合

## 2. Commit 规范

格式：

    type(scope): message

类型：

-   feat
-   fix
-   refactor
-   docs
-   test
-   chore

## 3. Pull Request

要求：

-   描述变更
-   添加测试
-   更新文档

## 4. 新功能

新增功能优先考虑：

-   Plugin
-   Extension
-   Adapter

避免修改核心 Runtime。
