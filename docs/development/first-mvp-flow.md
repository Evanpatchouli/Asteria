# First MVP Flow

版本：v0.1

## 1. MVP 目标

实现：

一个能够响应 AI Coding 状态的桌面宠物。

## 2. MVP 流程

    启动应用

    ↓

    创建透明窗口

    ↓

    加载默认宠物

    ↓

    显示 Idle 动画

    ↓

    模拟 Agent Event

    ↓

    切换 Coding 动画

    ↓

    接入 Claude Hook

    ↓

    真实响应

## 3. MVP 不包含

暂不实现：

-   Live2D
-   VRM
-   语音
-   长期记忆
-   插件市场
-   多角色生态

## 4. 验收标准

-   宠物可显示
-   动画稳定 60 FPS
-   Event 可以驱动状态变化
-   Claude Code 可以触发行为
