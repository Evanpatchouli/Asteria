# ADR-001: Choose Electron

状态：Accepted

## Context

项目需要：

-   Windows Desktop
-   Transparent Window
-   WebGL Rendering
-   AI SDK Integration

## Decision

选择 Electron。

## Reasons

-   Chromium 渲染稳定
-   Node.js 生态丰富
-   WebGL 支持成熟
-   开发效率高

## Alternatives

Tauri:

优势： - 更小体积

不足： - 生态较弱

Lynx:

优势： - 跨端潜力

不足： - 桌面生态仍在发展。
