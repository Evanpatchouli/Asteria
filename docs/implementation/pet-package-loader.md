# Pet Package Loader

版本：v0.1

## 1. 目标

加载宠物资源包。

## 2. 流程

    Load Package

    ↓

    Parse Manifest

    ↓

    Load Asset

    ↓

    Register Renderer

## 3. Package

    pet/

    ├── pet.json

    ├── animations/

    ├── textures/

    └── sounds/

## 4. 支持资源

-   Sprite
-   Spine
-   Live2D
-   VRM
