# Lumi 动画锚点、节奏与平滑度修复

## 症状

- 空闲状态在跨越源图上下两行时出现约 `40px` 的纵向跳动
- 思考状态跨行约跳动 `52px`，并伴随横向漂移
- 成功动画前段跑跳过快，最后 `yeah!` 停留约 `1.75s`
- PixiJS Canvas 以 60Hz 更新，但六张关键姿势只按 6–12 FPS 硬切

## 根因

- 固定 `256×256` 帧只统一了画布尺寸，没有统一角色在画布中的语义根部
- 图集关键姿势数量少，`AnimatedSprite` 不会自动生成中间过渡
- 成功序列通过重复最后一帧填满 Runtime 的 `2.4s` 瞬态时间

## 修复

- 资产构建器使用底部支撑带中心计算每帧 `anchor`
- 空闲只使用固定趴姿和尾巴关键帧，静止 `2.2s` 后快速摇尾 `0.3s`
- 思考、编码、工具调用与错误动画固定语义根部
- 成功动画改为 `0.8s` 跑动、`0.8s` 回旋跳、`0.4s` 落地和
  `0.4s` `yeah!`
- 将带字落地帧与无字落地帧分离
- Renderer 使用双 Sprite 和私有 `60Hz` Ticker 平滑过渡相邻关键姿势
- 新增资源校验器检查锚点、裁切、序列、重复比例和成功动画时长

## 边界

- 没有批量生成每秒 60 张 AI 位图，避免身份闪烁、图集膨胀和显存浪费
- 大跨度姿势过渡仍可能出现短暂重影，应通过增加真实关键姿势继续改善
- React 继续只负责低频 UI，不参与动画时间轴
